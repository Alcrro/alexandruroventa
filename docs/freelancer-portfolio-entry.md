# Freelancer Portfolio Entry — Personal Portfolio Website

## Title
Personal Portfolio Website — Next.js 14 Full-Stack Web App

## Description
Built a personal portfolio from scratch to showcase experience, projects, skills, and certificates. The app uses Next.js 14 App Router with server components, MongoDB/Mongoose for dynamic content, and a custom design system with Tailwind CSS + SCSS tokens. Features include dark/light theme, Framer Motion animations, an intercepting-route modal for the contact form (via Resend email API), and a certificate gallery with slug-based detail pages. Deployed on AWS Amplify with Route 53 for DNS. All data is fetched server-side through internal API routes with ISR revalidation.
