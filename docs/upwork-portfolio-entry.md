# Upwork Portfolio Entry — Personal Portfolio Website

## Project title
Personal Portfolio — Next.js 14 Full-Stack Web App

## Your role
Full-Stack Developer

## Project description
Built a personal portfolio site from scratch to showcase experience, projects, skills, and certificates. The app uses Next.js 14 App Router with server components, MongoDB/Mongoose for dynamic data, and a custom design system built with Tailwind CSS and SCSS tokens. Key features include a dark/light theme, smooth Framer Motion animations, an intercepting-route modal for the contact form (powered by Resend), and a certificate gallery with slug-based detail pages. Deployed on AWS Amplify with Route 53 for DNS. All data is fetched server-side through internal API routes with ISR revalidation for performance.
